# Original placeholder asset pack

These SVGs use a 32 px logical grid, crisp edges, and the project palette. They are original, editable source assets intended for Godot import or replacement with final sprite sheets.

- `logo.svg`: title treatment.
- `sprites/chef.svg`: chef player sprite.
- `sprites/chef_idle_v2.png`: four normalized 128×128 idle frames extracted from the supplied concept art.
- `sprites/chef_attack_v2.png`: four normalized 128×128 attack frames extracted from the supplied concept art.
- `sprites/chef_attack_butter_v1.png`: revised four-frame chef throw with butter preparation and release.
- `sprites/butter_projectile_v1.png`: four 64×64 spinning butter-projectile frames.
- `sprites/enemies.svg`: five enemy cells, in the same order used by the data catalog.
- `sprites/enemy_ispettore_walk_v2.png`: four 128×128 doctor/inspector walk frames.
- `sprites/enemy_turista_walk_v2.png`: four 128×128 gym-tourist walk frames.
- `sprites/enemy_ladro_walk_v2.png`: four 128×128 protester/thief walk frames.
- `sprites/enemy_*_death_v1.png`: four-stage fall animations for all active human enemies.
- `sprites/drop_guanciale_v1.png` and `sprites/drop_olio_v1.png`: new enemy-pickup art.
- `sprites/ingredients.svg` and `sprites/attacks.svg`: pickup and food-attack cells.
- `tiles/biomes.svg`: Orto, Bosco, and Vigneto cells.
- `props/kitchen.svg`: portable kitchen.
- `ui/mobile_ui.svg`: virtual joystick and dash button mock-up.

The magenta background is a chroma-key placeholder for atlas extraction; it is not used by the current procedural-rendering prototype.
